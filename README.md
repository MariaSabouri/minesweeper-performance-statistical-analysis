# Statistical Analysis of Minesweeper Performance

A statistical analysis project investigating the relationship between Minesweeper performance and academic, demographic, and self-reported gaming-experience variables among students at Shahid Beheshti University.

## Overview

This project was conducted as part of an undergraduate Statistics course at Shahid Beheshti University in February 2024.

The study examined Minesweeper game performance across three winning rounds, focusing on efficiency scores and completion times. Participants were recruited from the Electrical Engineering, Computer Engineering, Biomedical Engineering, and Law programs.

## Objectives

- Analyze the relationships between performance scores across multiple rounds.
- Investigate correlations between completion times across rounds.
- Examine associations between game performance and academic major, GPA category, gender, and self-reported gaming proficiency.
- Explore differences between participant groups using statistical methods.

## Methodology

Gameplay data were collected through a Telegram bot and analyzed using statistical methods.

The analysis included:

- Descriptive statistics and data visualization
- Shapiro-Wilk tests for normality
- Correlation and regression analysis
- Bootstrap resampling
- Analysis of Variance (ANOVA)
- Violin plots and Q-Q plots

## Key Findings

- Performance scores across rounds showed positive relationships.
- Completion times across rounds were correlated.
- Performance-score distributions did not satisfy the normality assumption according to the reported Shapiro-Wilk tests.
- No statistically significant group differences were identified at the 0.05 significance level.

## Limitations

The study was limited by the relatively small usable dataset and the number of recorded winning rounds. The findings should therefore be interpreted cautiously and should not be generalized to the broader student population without further data.
